# «UrTV النظيف» / Clean UrTV: mockups and feasibility (no build)

Mockups (1920x1080, stand-in fonts: the real Thmanyah files are private): `clean-01-settings-row` (row, off), `clean-02-confirm`, `clean-03-home-ar-dark`, `clean-04-home-ar-light`, `clean-05-home-en-dark`, `clean-06-customise`, `clean-07-stock-removal`. Source: `clean.py` (`python3 design/43/clean.py /tmp/hc && node design/43/render.js /tmp/hc design/43`).

## A) Clean home: feasible from the TV itself, no ADB, no computer
It is only a set of the home's own switches applied at once, and one press back. Everything it hides already has an on/off in the home or the settings: the quick buttons (`hiddenQuick`: markets, matches, center, phone), the cards (the card/slot choices), the nudge cards (HomeNudge), the greeting (Greeting), the extra rows and the control-center pill. One key `clean` in the home's prefs plus a `clean_keep` list for «تخصيص» (apps bar always, one card, Wi-Fi mark, greeting, settings button; clock, date and next prayer always); the home reads it where it already reads those switches, and nothing is deleted or reset: turning it off puts the person's own choices back exactly (they are never overwritten, the clean mode only masks them). Works with every look and dark/light (it adds nothing new to draw). Costs: one prefs key, ~150 lines in MainActivity/ConfigSnapshot, the settings row and the sheet (the control-center tick list is the pattern), tests like the quick-bar's. Risk: low; kids mode and the family lock are untouched (the lock still asks where it asked).

## B) «تخلّص من واجهة المصنع»: what is possible
- **Without any computer and without ADB:** nothing that removes the stock launcher. A normal app cannot disable another app or take the HOME role silently (`pm disable-user` needs the shell). What we can do alone: ask Android to make UrTV the home (the existing «اجعل UrTV الشاشة الرئيسية» row opens Android's own home chooser) and hide our own clutter (part A).
- **With the setup's ADB path (the on-TV «إعداد تلفزيوني», SetupEngine over the TV's own local ADB, the person allows «تصحيح USB» once on the TV):** yes, the same steps `optimize/run.sh` does: switch the home (journal `home-switch.json`, `SetupDeadman` safety switch for 300 s, `SetupRevertReceiver`, `SetupRecovery`), disable (`pm disable-user`, never uninstall) the stock launcher and the safe bloat list from `optimize/lists`, with the ledger `disabled-by-us.txt`. The protected features list (`keep.txt`) is never touched: the engine only disables what a list names and checks each name against it. So «تخلّص» = run the existing home-switch + safe-list steps again from the clean-mode screen; nothing new has to be invented for the engine.
- **Needs a computer:** nothing in B, but the first time USB debugging is off the TV has to be told by the person (Developer options); a TV with no on-device ADB path (some Android 14 builds end background ADB jobs with the session) falls back to «اطلب من مساعدك الذكي» (docs/SETUP-PROMPT.md).

## Risks
1. **TVs where the setup wizard owns Wi-Fi** (setupwraith): the existing rule stands: we never switch it off by hand; the home switch pauses («Home switch paused»), the person forgets and rejoins Wi-Fi in the TV's settings, then the same step runs again. Clean mode must not offer B on such a TV until that is done.
2. **No home at all** if UrTV crashes after the stock one is off: a black screen, possibly a boot loop with Wi-Fi down (the reason `deadman.sh`/`SetupDeadman` exist).
3. A bloat item that something else needs: only the reviewed lists are used, never a free-form package.
4. Casting and some inputs (Chromecast, HDMI-CEC apps) rely on the wizard or launcher services: the cast choice (`cast.txt`) and `keep.txt` already protect them; clean mode must show them in the confirm.
5. The safety switch is a job on the TV: on TVs that end it with the ADB session it is «unavailable» and B must refuse, not proceed.

## Safety net proposed (all built from what exists)
- **«رجّع واجهة المصنع»** one press, in the clean-mode settings and in the failure screen: re-enables exactly what `disabled-by-us.txt` lists plus the stock home and the wizard (the journal's `stock_before`, `wizard_before`, `role_holder_before`), then makes the stock home the HOME holder. From the TV it needs the same local ADB (so keep USB debugging on while B is on); if ADB is gone, the person still has `optimize/restore-home.sh` from a computer.
- **Automatic restore if our home crashes twice at boot:** a small counter in `SetupBootReceiver` (boot completed, home not confirmed within N seconds → count; at 2 run the same restore). Today the safety switch covers only the first 300 s of a switch; the boot counter is what is new and the one real piece of work (it cannot rely on the home itself running, so it lives in the boot receiver and the app's ADB key).
- Keep USB debugging on while B is on, say so in the warning (mockup 07), and show «رجّع» on the clean home's settings row.
