# ساعة بعقارب: نماذج للموافقة (المسألة ٦٣، لم يُبنَ شيء)

ساعة بعقارب بدل الأرقام الكبيرة، بشكلين هادئين. كل الصور 1920x1080 (وواحدة 1280x720 للتأكد أنها تسع)، والوقت فيها ١٠:١٠.

- **مكانها في «كنبة»:** نفس صندوق الساعة الكبيرة الثابت (ScenePlan.fixedBox: من 601 إلى 1319 عرضًا، ومن 266 إلى 542 طولًا على 1080)،
  في الوسط، ما تتحرك. قطرها 276 على 1080 (ارتفاع الصندوق)، والتاريخ فوقها والشريط والتطبيقات تحتها كما هي اليوم.
- **في شاشة التوقف:** الساعة وحدها في الوسط بقطر 520، وتحتها التاريخ والصلاة القادمة.
- **بلا زخرفة:** لا إطار ولا حلقة ولا عقرب ثوانٍ ولا ظل ملوّن. عقرب الساعات وعقرب الدقائق ونقطة صغيرة في الوسط، وظل خفيف فقط ليُقرأ فوق الصورة.
