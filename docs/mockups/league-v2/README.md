# صفحة الدوري v2: نماذج للموافقة (4.5، لم يُبنَ شيء)

الدراسة والمبادئ في [docs/research/LEAGUE-DESIGN-STUDY.md](../../research/LEAGUE-DESIGN-STUDY.md).

النماذج مرسومة بألوان صفحة «المباريات» ومقاساتها نفسها: الورق الرملي، والبطاقات البيضاء، وحلقة التركيز الخضراء. المقاسات أطوال 1080p مضروبة
في `--u`. كل صورة بحجمين: ١٩٢٠×١٠٨٠ و١٢٨٠×٧٢٠. البيانات أمثلة، ليست نتائج حقيقية. الخط بديل، لأن ملفات Thmanyah غير موجودة في هذه النسخة.
الشعارات تُحمّل وقت العرض، ومكانها في النماذج دائرة فيها أول حرف من اسم النادي.

**القواعد في النماذج:**
- لا كبسولات ولا «·». الألسنة هي ألسنة `#mp-days` المسطّرة، ومربعات الشكل زواياها ٦ بكسل.
- المسافات هوامش، لا `gap`، ولا `inset` ولا `clamp` ولا `min()` (R10).
- الأرقام المتغيرة معزولة الاتجاه (`unicode-bidi:isolate`) وفي صناديق ثابتة العرض.

**ملاحظة R5:** أصغر نص في الصفحة (المفتاح، والتلميحات، واسم النادي تحت الهدّاف) يصير ١٤ بكسل تقريبًا على 720p. هذا نفس حجم الأسطر الصغيرة
في صفحة «المباريات» اليوم. أما الأرقام والأسماء فبين ١٧ و٢٠ بكسل. وإذا كان «الخط الكبير» مفعّلًا، فالجدول الكامل يحتاج تمريرًا بسيطًا.
