# Riyadh night: Unsplash candidates

The owner picks one. Until then the bundled night photo stays.

Both are under the [Unsplash License](https://unsplash.com/license), which allows bundling in an app.

The owner: «these have the glass in front». On these photos the glass clock stands in front of the buildings, with no
cut-out. The clock is at its one fixed place (digits 266 to 542, 718 wide, centred), and each photo is shown whole: it is
1920 px, so a tighter frame would be an upscale.
