# بطاقة لا تناسب الشكل (٤٫٤)

- في اختيار بطاقات الرئيسية: البطاقة التي لا تناسب الشكل الحالي يظهر تحت اسمها سطر عادي «ما يناسب هذا الشكل» (بلا شارة)، وتبقى قابلة للاختيار.
- إذا تغيّر الشكل (التخطيط أو الشكل الجاهز) إلى شكل لا تناسبه بطاقة: تُبدَّل بأقرب بطاقة من نوعها فقط (مواقيت اليوم ← الصلوات في صف، طقس الأيام ← طقس الساعات،
  الأذكار ← الآية)، ورسالة قصيرة واحدة. الأسهم والمباريات والمهام وجديد المسلسلات ليس لها بطاقة مختصرة من نوعها: تبقى ومعها السطر.
- اختيارك الأصلي محفوظ ويرجع إذا رجع الشكل. وما تختاره بنفسك وهو لا يناسب يبقى كما اخترته، مع السطر فقط.
- «لا يناسب»: الشريط تحت الساعة (التخطيط «كنبة») يأخذ البطاقات المختصرة فقط. ومع الساعة الزجاجية الكبيرة يبدأ الشريط تحت الأرقام (لا يغطيها أبدًا) فيقصر.
