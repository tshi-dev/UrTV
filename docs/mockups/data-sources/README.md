# «مصادر البيانات» (الإعدادات ← حول), 4.4

The owner's rule for every card and screen: where the data comes from is said once, here. Each source has a row with what it gives; OK on
one shows its terms, and «الإعداد» goes to the row of what it gives (Open-Meteo: «التحية والطقس» in «الموقع والطقس»). On the cards a
source is a tiny dim line at most (60% of the line it sits by, half its light) or nothing; Open-Meteo's CC BY credit stays on screen, that small.

The row is «مصادر البيانات», not «المصادر»: on the home screen «المصادر» is already the TV's inputs (HDMI), and «أسماء المصادر» is a row.
