# إعداد تلفزيوني، أبسط: نموذج للموافقة (4.4، لم يُبنَ شيء)

مراجعة البساطة ([docs/ui/SIMPLE.md](../../ui/SIMPLE.md)) على شاشات الإعداد من التلفزيون. الصندوق الواحد ونمط الخط الواحد يبقون مثل ما قرّر المالك
(560 × 486 dp، 22 / 17 / 14 sp: هنا 1120 × 972 px بخط IBM Plex بدل ثمانية). كل شاشة فيها شي واحد يسويه الشخص، والتركيز على الزر الأساسي بتعبئة
الشكل (مثل صفوف الإعدادات)، بلا حلقة زرقاء ولا زر ذهبي.

| الصورة | قبل (compact-setup-v2) | بعد |
|---|---|---|
| [01-start.png](01-start.png) | الترحيب، ومسار «تصحيح USB» كامل، ورمز الإنقاذ وخطوات Downloader، فوق الزر | سطر، وسطر صغير، و«جهّز كل شي». اللغة زر هادئ |
| [02-usb.png](02-usb.png) | داخل البداية دايم | صفحة لحالها، تطلع بس إذا «تصحيح USB» مطفي: ثلاث خطوات مرقّمة وزر يفتح الإعدادات، وتكمّل وحدها |
| [03-rescue.png](03-rescue.png) | داخل البداية | صفحة لحالها قبل الشغل: «صوّر هذا بجوالك» ورمز يفتح الدليل (فيه Downloader والكود) |
| [04-plan.png](04-plan.png) | خمسة أسطر («نسخة احتياطية»، «أذونات»، «القائمة الآمنة»…) و SmartTube | ثلاثة أسطر بكلام الشخص، و«تراجع» سطر. التطبيقات المقترحة بعد الإعداد |
| [05-working.png](05-working.png) | أسماء خمس خطوات (فحص، تجهيز، تثبيت، تفعيل، تقرير) | سطر ونسبة وشريط. شاشة «السماح بتصحيح USB؟» تبقى مثل ما هي (05-setup-dialog) |
| [06-done.png](06-done.png) | «دور الشاشة الرئيسية»، «مراقبة زر الرئيسية»، الرمز، إطفاء التصحيح، أربع حالات «لو صار شي» | «انتهى الإعداد»، سطر، «تم»، و«لو صار شي» هادئ يفتح الباقي. حالة المراقبة تطلع بس إذا فيها مشكلة |

ما يتغيّر: النص وترتيب الصفحات في SetupActivity (البداية، الخطة، النهاية). ما يتغيّر الشغل نفسه ولا الأسئلة ولا «تراجع».
المصدر في `src/` (`node src/render.js`).
