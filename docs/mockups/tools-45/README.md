# 4.5 tools: mockups for the owner

HTML drawings at the TV's size with a stand-in font (DejaVu Sans), 1920×1080 shown at 1280×720; not screenshots of the TV. Ideas from
tvOS Launcher (github.com/techgenius1/tvOS-Launcher, Apache-2.0); ours is built on our existing screens and the «إضافات تلفزيونك» add-on.

| Picture | What it shows |
|---|---|
| 01-inputs.png | «المصادر»: rename (as today) and «إخفاء» / «إظهار» per input; a hidden input stays in this list, dimmed, and leaves the «المصادر» row and the control centre |
| 02-taps.png | «أزرار الريموت» with three presses per button (ضغطة، ضغطتان، ثلاث); a button the TV shares between keys is told by its number; only a button with 2 or 3 presses waits a third of a second |
| 03-switcher.png | «التطبيقات المفتوحة» (a remote button or the control centre): the apps, the memory used of the total, «إيقاف» for one, «أغلق الكل»; ours and the system's are never stopped |
| 03b-switcher-nolink.png | the same where «إعداد تلفزيوني» never ran (no ADB link): «إيقاف» only stops the background, and the screen says so |
| 04-backup.png | «نسخة الإعدادات»: save to a USB drive or Downloads, restore with old → new shown first, all or nothing; never the PIN, Wi-Fi, tasks, photos or the person's own adhan |
