# الإعدادات بشكل couch-tv مع «منظر وساعة» (نموذج للموافقة، لم يُبنَ)

طلب المالك: لما يكون الشكل «منظر وساعة»، تكون الإعدادات مثل إعدادات couch-tv بالضبط. الأشكال الثانية تبقى على إعداداتنا الحالية.

## ما قرأناه من couch-tv

من `tv-home/web/app.css` قسم «Home settings»، و`app.js` (طريقة رسم الصفوف)، في Seagey/couch-tv (MIT) عند `1b3e49a`. القياسات على شاشة
١٩٢٠، والوحدة ١٦ بكسل (rem = عرض الشاشة ÷ ١٢٠):

| الجزء | couch-tv |
|---|---|
| اللوحة | الشاشة كلها فوق الرئيسية، `rgba(10,8,12,.8)` مع تمويه ٤٠ بكسل؛ هامش ٦٠ × ٨٠ |
| الأعمدة | الأقسام بعرض ٥٧٦، وبينها وبين الصفوف ٦٤ |
| العنوان | ٤٦ عريض (٧٠٠)، فوقه ٣٦ وتحته ٤٠ |
| القسم | ارتفاعه ٧٦، زواياه ٢٤، الخط ٢٨ (٦٠٠)؛ أيقونته في مربع ٥٢ (زواياه ١٦) لونه أبيض ١٠٪ |
| الصف | ارتفاعه ٧٦، حشوه ١٢ × ٢٨، زواياه ٢٤، أبيض ٨٪، الخط ٢٨؛ السطر تحته ٢٠ بشفافية ٦٠٪؛ القيمة في الطرف الثاني (٥٠٠، ٦٢٪) |
| عنوان مجموعة | ٢٠ (٦٥٠) بشفافية ٥٠٪ |
| التركيز | أبيض والنص `#111`؛ القسم يكبر ١٫٠٤ والصف ١٫٠٢، مع ظل؛ الحركة ٢٠٠ م.ث `cubic-bezier(.2,.8,.2,1)` |
| تشغيل وإيقاف | دائرة ٣٦ بحافة، تصير خضراء `#30d158` بعلامة لما يكون مفعّلًا |
| اختيار | علامة بجانب المختار، وصفحته في نفس المكان مع المسار فوق العنوان |
| رابط | سهم باهت |
| الفتح | تظهر مرة وحدة؛ مع الزجاج تستقر في ٣٨٠ م.ث (تلاشٍ وارتفاع ٨ بكسل). الأقسام تتبدّل بدون حركة |

## إعداداتنا بنفس الشكل

معكوسة للعربي: الأقسام يمين والصفوف يسار، القيمة في الطرف الأيسر، والسهم يشير لليسار. couch-tv ليس فيه بحث، فالبحث زر دائري بجانب
«الإعدادات»، ومربع الكتابة بشكل مربع couch-tv. الأقسام العشرة نفسها، وتتسع تحت العنوان (١٠ × ٨٢ من ٨٢٤ بكسل).
