# «زجاجي»: the glass dock, «كل التطبيقات» as glass, and the app icon changer (4.5, mockups only)

Pictures for the owner's approval; nothing is built yet. The ideas come from tvOS Launcher (github.com/techgenius1/tvOS-Launcher,
Apache-2.0, which credits Hume Launcher and Couch TV). No code, logo or photo of it is used here. If code is adapted when this is built,
THIRD_PARTY_NOTICES.md gets a tvOS Launcher section with its Apache-2.0 notice, and the adapted files keep its copyright lines.

1. A 4th way in «شكل التطبيقات», «زجاجي»: a liquid-glass bar at the bottom (frosted, a light edge on top), each app's icon as a
   rounded square (squircle), the focused one bigger with a light ring, its name floating above it alone. Size 50 to 150 %, 1 to 3 rows.
   - `glass-dock-a.png`: 100 %, one row.
   - `glass-dock-b.png`: 70 %, two rows.
   - `glass-dock-c.png`: 150 %, one row.
2. `glass-all-apps.png`: «كل التطبيقات» as a frosted-glass window over the home: its count, a search field (a rectangle with
   small corners), and a grid of five columns; the focused app in a light frame.
3. `glass-icon-editor.png`: a long OK on an app, then «تغيير الأيقونة»: an image from the TV's storage or a USB drive (or the app's
   own icon back), and a small editor: a background colour, and the shape (square, rounded square, circle), with a live preview.
   «حفظ» and «إلغاء» are rectangles.

Rules kept: Arabic first and right to left, no capsules, no «·». The icons here are neutral stand-ins (a colour and a plain shape),
not any app's logo; on the TV each installed app's own icon is drawn (PackageManager), and a changed icon is the person's own image.
The photos are UrTV's own backgrounds (assets/backgrounds). The font is a stand-in for Thmanyah.
