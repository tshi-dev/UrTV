# Issues audit for 4.4 beta 4: every reported problem, checked in the code

## ملخّص للمالك

راجعنا كل بلاغ وصلنا: بلاغات GitHub كلها (مفتوحة ومقفلة)، وملاحظات مستخدمي X (١٩ و٢٧ نوفمبر)، وكل صفوف سجل الرجوعات (٣٣٦ صف، R-001 إلى R-347)،
وقائمة «أخطاء معروفة لم تُصلح بعد» في السجل. ما اعتمدنا على سطر في CHANGELOG: فتحنا الكود وشغّلنا الاختبار لكل بند على beta 4 (`452fad87`).

**ملاحظات X كلها محلولة في beta 4 وعليها اختبارات**، ما عدا اثنتين:
- **رمز QR يفتح «لا يمكن الوصول إلى هذا الموقع»: جزئي.** العنوان في الرمز كان أصلاً `http://` كامل، والموجود في beta 4 سطر تحت كل رمز «ما فتح؟ اكتب العنوان في متصفح الجوال». السبب نفسه ما عرفناه بعد.
- **شكل البطاقات (الحجم والزوايا): موجود بدون اختبار.** الصفان والأمر `saver.sh cardsize` و`cardcorner` والـ CSS في الصفحة موجودة، لكن ما فيه اختبار يتأكد إن الإعداد يوصل للصفحة. وإضافة دعاء من الفلاشة شغّالة، بس الطريق نفسه بدون اختبار.

**بلاغات GitHub المفتوحة (١٢):** سبعة منها محلولة في beta 4 وتنتظر رد صاحب البلاغ أو قفل البلاغ: #19 و#57 و#60 و#61 و#62 و#64 و#67
(وفي #60 و#62 أكّد صاحب البلاغ إنها انحلّت). **#61 محلول وردّنا الأخير فيه غلط:** الشيخ أحمد طالب بن حميد موجود في beta 4 (١٠٧ سور، والناقصة يتخطاها المشغّل).
والمفتوح فعلاً: **#42** (شاشة التوقف على TCL 65C7K تحتاج إذن الظهور فوق التطبيقات، وتطلبه من جديد بعد كل انقطاع كهرباء)، و**#56** («أكمل المشاهدة» على Xiaomi)،
و**#63** (ساعة عقارب)، و**#68** (جزئي: «الكهف» والذهب ٢١ موجودة، والباقي مؤجّل بقرارك). **#37** محلول عن طريق «إضافات تلفزيونك» إلا على
التلفزيونات الضعيفة وأندرويد أقدم من ٩، وهذا مقصود.

**سجل الرجوعات:** كل الـ ٣٣٦ صف لها اختبار موجود، وشغّلنا مجموعة `regressions` كاملة على beta 4: نجح ١٩٢ ملف من ١٩٣، ونجح معها اختبارا الصفحة
اللي تحتاج متصفح. الملف الوحيد اللي ما نجح هنا `tests/check.py`، لأنه يحتاج الخطوط الخاصة اللي تجي في CI بس، وما فيه صف يعتمد عليه وحده.

**قرارات تحتاجك:** (١) نرد على #61 و#60 و#62 ونقفلها؟ (٢) لـ #42: نضيف إذن `SYSTEM_ALERT_WINDOW` لتطبيق شاشة التوقف (إذن جديد في التحديث)؟
(٣) قائمة «أخطاء معروفة» فيها ٢٦ بند، بعضها قديم ولازم نراجعه (التفاصيل تحت).

## Scope and method

- Base: `origin/work/44-beta4` at `452fad8759a9a15c723361d87747fc8360964419`. Nothing in the app's code was changed. This file is the only change.
- Sources: the 70 issues and PRs of the repository (state all, with every comment). The closed «data health» bot issues (#69, #70) and the PRs are left out:
  the PRs are contributions, not reports, and the issues they answer are rows below. Also read: CHANGELOG.md, `docs/dev/REGRESSIONS.md` (every R-row
  and the «Known bugs» list), `docs/research/SETTINGS-FINDABILITY.md` (the three features people on X could not find), and the git log.
- Not read: the private reports repository (no access from this session). Reports that exist only there are not in this audit.
- For each item: the code at the line named was read, and the test named was run on beta 4 in this container (python3, javac, node and Playwright).
  `tests/check.py` needs the private font files (CI only) and was not run here.
- Verdicts: **OPEN** not fixed. **PARTIAL** part of it fixed. **SOLVED-NO-TEST** fixed, but no test fails if the fix is reverted. **WON'T** an owner
  decision, with where it is recorded. **SOLVED** fixed, with a test that passed on beta 4.
- No reporter names or handles appear here. The X reports are given by date only.
